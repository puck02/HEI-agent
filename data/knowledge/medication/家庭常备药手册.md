## 二、常见家庭场景用药指南

### 场景1：感冒发烧

**症状判断与用药方案：**

```
发热（体温≥37.3°C）
├── 低热（37.3-38°C）
│   ├── 物理降温（温水擦浴、多饮水）
│   └── 暂不用退热药，观察
├── 中度发热（38.1-39°C）
│   ├── 对乙酰氨基酚 300-600mg（成人）/ 10-15mg/kg（儿童）
│   └── 或布洛芬 200-400mg（成人）/ 5-10mg/kg（儿童）
└── 高热（>39°C）
    ├── 退热药 + 物理降温
    ├── 多饮水，注意脱水
    └── 持续不退或超过3天 → 就医
```

**伴鼻塞流涕：** 加用含伪麻黄碱的感冒药
**伴咳嗽：** 干咳用右美沙芬；有痰用氨溴索
**伴咽痛：** 西瓜霜含片、淡盐水漱口

**⚠️ 注意事项：**
- 两种退热药不建议交替使用（除非医生指导）
- 儿童发热期间注意观察精神状态
- 出现热性惊厥立即就医

### 场景2：腹泻

**腹泻分类处理：**

```
急性腹泻
├── 水样便、无脓血、无高热
│   ├── 首要：口服补液盐预防脱水
│   ├── 蒙脱石散止泻（与其他药物间隔2小时）
│   └── 益生菌（双歧杆菌等）调节肠道菌群
├── 血便或脓血便
│   └── ⚠️ 立即就医（可能是细菌性痢疾等）
└── 伴高热（>38.5°C）
    └── ⚠️ 就医检查

儿童腹泻特别注意：
- 脱水是最大风险，必须及时补液
- 口服补液盐Ⅲ（低渗配方）为首选
- 不建议自行使用止泻药（洛哌丁胺禁用于2岁以下儿童）
- 继续喂养，不要禁食
```

**脱水程度判断：**
| 程度 | 表现 | 处理 |
|------|------|------|
| 轻度 | 口渴、尿量略减 | 口服补液 |
| 中度 | 眼窝凹陷、皮肤弹性下降、少尿 | 大量口服补液，考虑就医 |
| 重度 | 意识模糊、无尿、四肢冰冷 | ⚠️ 立即就医/急诊 |

### 场景3：外伤处理

**小伤口处理步骤：**
1. **止血**：用干净纱布按压5-10分钟
2. **清洗**：用流动清水或生理盐水冲洗伤口
3. **消毒**：用碘伏从伤口中心向外周涂擦
4. **包扎**：用创可贴或纱布覆盖
5. **观察**：注意有无红肿、化脓等感染迹象

**需要就医的外伤：**
- 伤口较深、较宽，可能需要缝合
- 出血不止（按压15分钟仍出血）
- 动物咬伤（需注射狂犬疫苗）
- 生锈铁器刺伤（需注射破伤风疫苗）
- 伤口内有异物无法取出
- 面部伤口（影响美观需精细缝合）

### 场景4：过敏反应

**轻度过敏（可居家处理）：**
- 皮肤瘙痒、局部荨麻疹
- 轻微鼻塞、流涕
- **处理**：口服氯雷他定10mg，每日1次；炉甘石洗剂外涂

**重度过敏（⚠️ 立即拨打120）：**
- 呼吸困难、喉头紧缩感
- 面部/口唇肿胀
- 头晕、血压下降
- 全身大面积皮疹
- **等待救援时**：让患者平躺，抬高下肢；如有肾上腺素笔可自行注射

### 场景5：胃痛/胃酸过多

```
胃痛/反酸/烧心
├── 偶尔发作（与饮食相关）
│   ├── 铝碳酸镁片 嚼服（快速中和胃酸）
│   ├── 调整饮食：少食多餐，避免辛辣刺激
│   └── 避免饭后立即平躺
├── 频繁发作
│   ├── 奥美拉唑 20mg 每日1-2次（不超过14天）
│   └── ⚠️ 建议就医检查
└── 伴以下症状立即就医
    ├── 剧烈腹痛
    ├── 呕血或黑便
    ├── 体重明显下降
    └── 吞咽困难
```

## 三、家庭药箱管理规范

### 1. 药箱设置建议

**存放位置：**
- ✅ 客厅高处柜子（方便取用，远离儿童）
- ✅ 卧室衣柜上层
- ❌ 厨房（温度高、湿度大）
- ❌ 浴室（湿度大）
- ❌ 窗台（阳光直射）
- ❌ 冰箱门上（温度波动大，除需冷藏药物外）

**分类建议（使用分隔盒）：**
```
┌─────────────────────────────────────────┐
│ 家庭药箱                                 │
├────────┬────────┬────────┬──────────────┤
│ 内服药  │ 外用药  │ 器械耗材 │ 特殊药物     │
│        │        │        │ (需冷藏等)    │
├────────┼────────┼────────┼──────────────┤
│退热药   │碘伏    │创可贴   │胰岛素(冷藏)  │
│感冒药   │酒精    │纱布    │              │
│止泻药   │止痒药  │棉签    │              │
│胃药     │消炎膏  │体温计  │              │
│过敏药   │        │        │              │
└────────┴────────┴────────┴──────────────┘
```

### 2. 定期维护计划

| 频率 | 检查内容 |
|------|---------|
| **每月** | 检查有无变色、变质的药品 |
| **每季度** | 检查有效期，清理近期将过期药品 |
| **每半年** | 全面清点，补充消耗品 |
| **每年** | 彻底整理，更新药品清单 |

### 3. 药品有效期速记

**药品开封后使用期限参考：**
| 剂型 | 开封后有效期 | 存储要求 |
|------|------------|---------|
| 普通片剂/胶囊 | 6个月或原有效期（取较短者） | 密封、阴凉 |
| 口服液/糖浆 | 开封后1-3个月 | 阴凉处，拧紧瓶盖 |
| 眼药水 | 开封后4周 | 避光、阴凉 |
| 软膏/乳膏 | 开封后6个月 | 阴凉处 |
| 栓剂 | 开封后尽快使用 | 阴凉或冷藏 |
| 胰岛素（开封后） | 28天 | 室温25°C以下 |
| 胰岛素（未开封） | 原有效期 | 冷藏2-8°C |

## 四、四季用药提示

### 🌸 春季
- **过敏高发**：花粉过敏增多，备好氯雷他定/西替利嗪
- **流感余波**：春季仍有流感流行，注意感冒药储备
- **蚊虫复苏**：备好炉甘石洗剂、蚊虫叮咬膏

### ☀️ 夏季
- **防暑降温**：备藿香正气水/液、人丹
- **腹泻高发**：食物易变质，备足口服补液盐、蒙脱石散
- **皮肤问题**：备足防晒用品、止痒药膏
- **创可贴**：夏天活动多，小外伤增加

### 🍂 秋季
- **秋燥**：备润喉含片、人工泪液
- **换季感冒**：气温变化大，备好感冒药
- **胃肠道**：秋季胃肠疾病增加

### ❄️ 冬季
- **感冒流感高发**：重点储备退热药、感冒药
- **冻伤**：寒冷地区备冻伤膏
- **皮肤干燥**：备保湿润肤霜
- **心血管**：有心血管疾病患者的老人，确保日常用药充足

## 五、特殊人群家庭药箱补充

### 有老人的家庭（额外储备）
- 血压计（电子臂式，更准确）
- 速效救心丸（冠心病患者）
- 硝酸甘油（冠心病患者，舌下含服）
- 降压药（日常用药，备1-2周额外量）
- 健胃消食片（消化功能减弱）
- 开塞露（老年人便秘常见）
- 骨折固定夹板（老年人骨质疏松易骨折）

### 有婴幼儿的家庭（额外储备）
- 儿童退热栓（对乙酰氨基酚栓/布洛芬栓）
- 儿童用退热药混悬液
- 生理盐水滴鼻液（缓解鼻塞）
- 儿童用益生菌
- 护臀膏（预防尿布疹）
- 吸鼻器（清理鼻涕）
- 退热贴
- 婴儿体温计（耳温枪或额温枪）

### 有慢性病患者的家庭
- 确保日常用药**至少储备2周**的量
- 定期检查慢病药物有效期
- 建立**用药提醒机制**（闹钟、分药盒）
- 保存好处方记录，方便续方

## 六、过期药品处理

### 正确处理方式
1. **不要直接丢入垃圾桶**：可能被他人捡拾或污染环境
2. **不要倒入马桶/下水道**：污染水源
3. **正确做法**：
   - 送到附近药店的**过期药品回收箱**
   - 送到社区卫生服务中心的**药品回收点**
   - 将药品从包装中取出，混入咖啡渣/猫砂后密封丢弃（无回收条件时）

### 处理前准备
- 撕掉或涂黑包装上的个人信息
- 将药品与包装分开
- 液体药品用纸巾吸收后密封
