# 处方药与非处方药分类管理知识

> 资料来源：《中华人民共和国药品管理法》、国家药品监督管理局
> 更新时间：2025年

---

## 一、药品分类管理概述

### 我国药品分类体系

```
药品分类
├── 处方药（RX）
│   ├── 甲类处方药：必须在医疗机构使用
│   └── 乙类处方药：可在药店凭处方购买
├── 非处方药（OTC）
│   ├── 甲类OTC（红标）：须在药师指导下购买使用
│   └── 乙类OTC（绿标）：可自行选购，安全性更高
└── 特殊管理药品
    ├── 麻醉药品（如吗啡、哌替啶）
    ├── 精神药品（一类：如氯胺酮；二类：如地西泮）
    ├── 医疗用毒性药品（如砒霜、水银）
    └── 放射性药品
```

### OTC药物遴选原则
1. 应用安全：不良反应发生率低，无严重不良反应
2. 疗效确切：适应症明确，治疗效果肯定
3. 质量稳定：质量可控，不易变质
4. 使用方便：无需专业给药技术，可自行使用

## 二、处方药与OTC药对比

| 特征 | 处方药（RX） | 非处方药（OTC） |
|------|------------|---------------|
| 购买方式 | 需凭医师处方 | 可自行购买 |
| 使用指导 | 医师处方、药师调配 | 自我判断或药师指导 |
| 安全性 | 需专业评估 | 相对安全 |
| 标识 | RX标识 | OTC标识（红/绿） |
| 适应症范围 | 较广，包括严重疾病 | 常见轻微疾病 |
| 不良反应 | 可能较重 | 一般较轻 |
| 使用期限 | 按处方规定 | 按说明书 |

## 三、常见处方药类别（了解）

> 以下药物需凭处方购买，不可自行使用。了解这些知识有助于配合医生治疗。

### 1. 抗生素（多数为处方药）

| 分类 | 常见药物 | 处方状态 |
|------|---------|---------|
| 青霉素类 | 阿莫西林、氨苄西林 | 处方药 |
| 头孢类 | 头孢克肟、头孢丙烯 | 处方药 |
| 大环内酯类 | 阿奇霉素、克拉霉素 | 处方药 |
| 喹诺酮类 | 左氧氟沙星、莫西沙星 | 处方药 |
| 甲硝唑 | 甲硝唑片 | 处方药 |

**少数例外**：部分OTC药品含抗菌成分（如复方新诺明的部分剂型）

### 2. 降压药（均为处方药）

| 分类 | 代表药物 |
|------|---------|
| ACEI类 | 依那普利、贝那普利 |
| ARB类 | 缬沙坦、氯沙坦 |
| CCB类 | 氨氯地平、硝苯地平控释片 |
| β受体阻滞剂 | 美托洛尔、比索洛尔 |
| 利尿剂 | 氢氯噻嗪、呋塞米 |

### 3. 降糖药（多数为处方药）

| 分类 | 代表药物 |
|------|---------|
| 双胍类 | 二甲双胍 |
| 磺脲类 | 格列美脲、格列齐特 |
| DPP-4抑制剂 | 西格列汀 |
| SGLT-2抑制剂 | 达格列净 |
| GLP-1受体激动剂 | 利拉鲁肽 |
| 胰岛素 | 各种胰岛素 |

### 4. 降脂药（多数为处方药）

| 分类 | 代表药物 |
|------|---------|
| 他汀类 | 阿托伐他汀、瑞舒伐他汀 |
| 贝特类 | 非诺贝特 |
| 胆固醇吸收抑制剂 | 依折麦布 |

### 5. 精神类药品

| 分类 | 代表药物 | 管理级别 |
|------|---------|---------|
| 抗抑郁药 | 舍曲林、氟西汀 | 处方药 |
| 抗焦虑药 | 阿普唑仑、地西泮 | 二类精神药品 |
| 催眠药 | 唑吡坦、佐匹克隆 | 处方药 |
| 抗精神病药 | 奥氮平、利培酮 | 处方药 |

## 四、如何正确获取处方药

### 线下购药流程
1. **挂号就诊**：到医院或诊所就诊
2. **医生开处方**：根据诊断开具处方
3. **药房取药**：在医院药房或凭处方到药店购药
4. **药师审核**：药师核对处方、调配药品、交代用法

### 线上购药流程（互联网医院）
1. **选择合法平台**：确认平台有《互联网诊疗许可证》
2. **在线问诊**：通过图文/视频与医生沟通
3. **电子处方**：医生开具电子处方
4. **在线购药配送**：选择配送方式

### 续方注意事项
- 慢性病用药可申请**长处方**（最长12周）
- 续方前建议定期复查相关指标
- 部分药物需要定期检查肝肾功能

## 五、OTC药物自我药疗指南

### 适合自我药疗的情况
- ✅ 普通感冒（无并发症）
- ✅ 轻度头痛、发热
- ✅ 轻度消化不良
- ✅ 轻度皮肤瘙痒
- ✅ 轻度腹泻（无血便、无高热）
- ✅ 轻度便秘
- ✅ 轻度过敏（无呼吸困难）
- ✅ 口腔溃疡
- ✅ 蚊虫叮咬

### 不适合自我药疗的情况（应就医）
- ❌ 不明原因的症状
- ❌ 持续或加重的症状
- ❌ 伴有高热、出血等严重症状
- ❌ 慢性病的变化或新发症状
- ❌ 精神心理问题
- ❌ 儿童、孕妇、老人的复杂症状

## 六、药品说明书解读

### 如何阅读药品说明书

```
药品说明书结构：
1. 【药品名称】通用名（必须使用）和商品名
2. 【成分】活性成分和辅料
3. 【性状】外观描述
4. 【适应症】治疗什么疾病/症状
5. 【规格】每片/粒的含量
6. 【用法用量】怎么吃、吃多少          ← 重点阅读
7. 【不良反应】可能出现的副作用          ← 重点阅读
8. 【禁忌】哪些人不能用                 ← 重点阅读
9. 【注意事项】使用中的注意点            ← 重点阅读
10.【药物相互作用】与其他药同用的影响     ← 重点阅读
11.【贮藏】如何保存
12.【有效期】可使用期限
13.【批准文号】国药准字号
```

### 说明书关键信息解读

**"禁用" vs "慎用" vs "忌用"：**
| 术语 | 含义 | 严重程度 |
|------|------|---------|
| **禁用** | 绝对不能使用 | 🔴 最严重 |
| **忌用** | 最好不用，风险大于获益 | 🟠 严重 |
| **慎用** | 可用但需密切观察 | 🟡 需注意 |

**"尚不明确"的含义：**
- 说明书中"不良反应：尚不明确"不代表没有不良反应
- 可能是因为上市后研究不足，数据有限
- 不代表该药物绝对安全

## 七、药品价格与医保

### 医保药品分类
- **甲类药品**：医保全额报销（按比例）
- **乙类药品**：医保部分报销，个人需自付一定比例
- **丙类药品/目录外**：全部自费

### 如何节省药费
1. 优先选择医保目录内的通用名药品
2. 集中采购（集采）药品价格更实惠
3. 同成分药品中，仿制药价格通常低于原研药
4. 善用药店会员优惠
5. 关注各地惠民保等补充保险
