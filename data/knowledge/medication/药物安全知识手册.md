# 药物安全知识手册

> 资料来源：国家药品监督管理局（NMPA）安全用药科普、世界卫生组织（WHO）患者安全指南、中国药学会
> 更新时间：2025年

---

## 一、用药安全基本原则

### 1. "五个正确"原则（Five Rights）
用药安全的核心是确保以下五个要素正确：

| 要素 | 说明 |
|------|------|
| **正确的药物** | 确认药名，避免发音相似药品混淆 |
| **正确的剂量** | 严格按照医嘱或说明书剂量 |
| **正确的时间** | 按规定时间间隔给药 |
| **正确的途径** | 口服、外用、注射等给药方式正确 |
| **正确的患者** | 确认药品是给该患者的（家庭内尤为重要） |

### 2. 用药前检查清单
- [ ] 确认药品名称与处方一致
- [ ] 检查有效期
- [ ] 确认剂量
- [ ] 了解给药时间（餐前/餐后/空腹）
- [ ] 了解该药物的禁忌症
- [ ] 了解可能的不良反应
- [ ] 确认与正在使用的其他药物无相互作用

## 二、药物相互作用

### 1. 药物-药物相互作用

#### 严重相互作用示例：

| 药物A | 药物B | 相互作用后果 | 严重程度 |
|-------|-------|-------------|---------|
| 华法林 | 阿司匹林 | 出血风险大幅增加 | 🔴 严重 |
| 他汀类 | 红霉素/克拉霉素 | 横纹肌溶解风险 | 🔴 严重 |
| 降压药 | 布洛芬 | 降压效果减弱 | 🟡 中等 |
| 甲氨蝶呤 | 布洛芬 | 甲氨蝶呤毒性增加 | 🔴 严重 |
| 地高辛 | 胺碘酮 | 地高辛中毒 | 🔴 严重 |
| 口服避孕药 | 利福平 | 避孕效果降低 | 🟡 中等 |
| 降糖药 | 酒精 | 低血糖风险 | 🔴 严重 |
| ACE抑制剂 | 钾补充剂 | 高钾血症 | 🟡 中等 |

### 2. 药物-食物相互作用

| 药物 | 避免的食物/饮品 | 原因 |
|------|---------------|------|
| **华法林** | 大量绿叶蔬菜（富含维生素K） | 降低抗凝效果 |
| **他汀类** | 西柚/葡萄柚 | 抑制药物代谢，增加毒性 |
| **四环素类抗生素** | 牛奶、钙片、铁剂 | 形成络合物，影响吸收 |
| **单胺氧化酶抑制剂** | 奶酪、腌肉、啤酒 | 高血压危象 |
| **左旋甲状腺素** | 豆制品、咖啡 | 影响吸收 |
| **铁剂** | 茶、牛奶、咖啡 | 降低铁吸收 |
| **所有药物** | 酒精 | 增加不良反应风险 |

### 3. 药物-疾病相互作用（疾病禁忌）

| 药物类型 | 禁忌疾病 | 原因 |
|---------|---------|------|
| 布洛芬等NSAIDs | 胃溃疡 | 加重消化道出血 |
| β受体阻滞剂 | 哮喘 | 可诱发支气管痉挛 |
| 伪麻黄碱 | 高血压 | 升高血压 |
| 含氯苯那敏药物 | 青光眼、前列腺肥大 | 加重症状 |
| 糖皮质激素 | 糖尿病 | 升高血糖 |
| 苯海拉明 | 重症肌无力 | 加重肌无力 |

## 三、特殊人群用药安全

### 1. 老年人用药（65岁以上）

**老年人用药特点：**
- 肝肾功能减退，药物代谢排泄减慢
- 多病共存，多重用药风险高
- 对药物不良反应更敏感

**安全建议：**
1. **从小剂量开始**：一般从成人剂量的1/2至2/3开始
2. **定期清理药箱**：至少每6个月审查一次用药
3. **使用药物分装盒**：避免漏服或重复服药
4. **做好用药记录**：记录药名、剂量、时间
5. **告知医生全部用药**：包括中药、保健品
6. **预防跌倒**：注意药物是否引起头晕、体位性低血压

### 2. 儿童用药

**关键原则：**
- **儿童不是缩小版的成人**，不可简单将成人药减量
- **优先选择儿童专用剂型**（混悬液、颗粒剂）
- **严格按体重计算剂量**
- **禁用或慎用的药物**：
  - **阿司匹林**：16岁以下禁用（Reye综合征）
  - **喹诺酮类**（如左氧氟沙星）：影响软骨发育
  - **四环素类**：8岁以下禁用（牙齿着色）
  - **氯霉素**：新生儿"灰婴综合征"
  - **含可待因的止咳药**：12岁以下禁用
  - **氨基糖苷类**（如庆大霉素）：耳毒性和肾毒性

**常见儿童退热药剂量：**
| 药物 | 剂量 | 适用年龄 |
|------|------|---------|
| 对乙酰氨基酚 | 10-15mg/kg/次 | 3个月以上 |
| 布洛芬 | 5-10mg/kg/次 | 6个月以上 |

### 3. 孕妇和哺乳期用药

**FDA妊娠药物分级（参考）：**
| 分级 | 含义 | 举例 |
|------|------|------|
| A | 对胎儿安全 | 适量维生素、叶酸 |
| B | 动物实验未见风险 | 对乙酰氨基酚（短期）、头孢类 |
| C | 风险不能排除 | 布洛芬（孕早/中期）、大部分感冒药 |
| D | 有胎儿风险证据 | 华法林、四环素 |
| X | 孕期禁用 | 异维A酸、甲氨蝶呤 |

**孕期安全用药建议：**
1. 孕期任何用药前咨询医生
2. 孕早期（前3个月）尽量避免用药
3. **可安全使用**：对乙酰氨基酚（短期）、部分头孢类抗生素
4. **孕期禁用**：异维A酸、华法林、四环素、利巴韦林

**哺乳期注意：**
- 大多数药物可少量分泌到乳汁中
- 用药时间建议在**刚喂完奶后**
- 对乙酰氨基酚、布洛芬通常被认为哺乳期安全
- 用药前查阅药物说明书中的"哺乳期用药"信息

### 4. 肝肾功能不全患者

**肝功能不全：**
- 避免使用肝毒性药物（对乙酰氨基酚、甲氨蝶呤等）
- 经肝脏代谢的药物需减量或延长给药间隔
- 定期监测肝功能指标

**肾功能不全：**
- 经肾脏排泄的药物需根据肾功能调整剂量
- 避免使用肾毒性药物（氨基糖苷类、NSAIDs长期使用等）
- 常用"肌酐清除率"来评估肾功能并调整剂量

## 四、药物不良反应识别与处理

### 1. 什么是药物不良反应（ADR）？

药物不良反应是指在正常用法用量下出现的与用药目的无关的有害反应。包括：
- **副作用**：治疗剂量下出现的非预期效应
- **毒性反应**：剂量过大或长期使用导致
- **过敏反应**：免疫系统介导的反应
- **继发反应**：药物作用引起的间接效应
- **特异质反应**：与遗传因素有关的异常反应

### 2. 严重不良反应信号

**出现以下症状应立即停药并就医：**
- 🔴 **皮肤反应**：严重皮疹、水疱、皮肤剥脱
- 🔴 **呼吸困难**：喉头水肿、喘息
- 🔴 **过敏性休克**：血压骤降、意识模糊、面色苍白
- 🔴 **肝损伤信号**：黄疸（皮肤/眼睛发黄）、深色尿液、右上腹痛
- 🔴 **肾损伤信号**：尿量明显减少、水肿
- 🔴 **出血征象**：异常瘀斑、黑便、血尿
- 🔴 **严重胃肠反应**：剧烈腹痛、呕血
- 🟡 **神经症状**：持续头痛、眩晕、耳鸣

### 3. 药物过敏史管理

**重要建议：**
1. **记录所有过敏药物**，包括具体反应表现
2. **随身携带过敏信息卡**或在手机中记录
3. **每次就医时主动告知**医生和药师
4. **交叉过敏注意**：
   - 青霉素过敏者：对头孢类约10%交叉过敏
   - 磺胺过敏者：对部分利尿剂、降糖药可能交叉过敏
   - 造影剂过敏者：对贝类过敏不一定相关（旧观点已更正）

## 五、抗生素合理使用

### 1. 抗生素使用基本原则

> ⚠️ **抗生素≠消炎药**，抗生素只对细菌感染有效，对病毒感染（普通感冒、流感）无效。

**正确使用原则：**
1. **有明确细菌感染指征才使用**（如血常规显示白细胞升高）
2. **遵医嘱完成疗程**：一般7-14天，不可症状好转就停药
3. **按时给药**：保持稳定的血药浓度
4. **不自行购买**：抗生素多为处方药（RX），需医生处方
5. **不要要求医生开抗生素**：信任医生的专业判断

### 2. 常见抗生素分类

| 类别 | 代表药物 | 常见用途 | 主要不良反应 |
|------|---------|---------|------------|
| 青霉素类 | 阿莫西林 | 上呼吸道感染 | 过敏反应 |
| 头孢类 | 头孢克肟、头孢地尼 | 呼吸道/泌尿道感染 | 过敏、腹泻 |
| 大环内酯类 | 阿奇霉素、红霉素 | 支原体感染 | 胃肠反应 |
| 喹诺酮类 | 左氧氟沙星 | 泌尿道/呼吸道感染 | 肌腱损伤(成人) |
| 硝基咪唑类 | 甲硝唑 | 厌氧菌感染/牙科 | 禁止饮酒 |

### 3. 抗生素耐药性

**细菌耐药的严重性：**
- 全球每年约70万人死于耐药菌感染（WHO数据）
- 不合理使用抗生素是耐药性产生的主要原因
- "超级细菌"（如MRSA）对多数抗生素耐药

**个人层面如何应对：**
1. 不自行使用抗生素
2. 不与他人共用抗生素
3. 完成完整疗程
4. 不使用剩余的抗生素
5. 接种疫苗减少感染机会

## 六、药物存储安全

### 1. 家庭药箱管理

**存储条件分类：**

| 存储条件 | 温度范围 | 适用药物 |
|---------|---------|---------|
| 室温保存 | 15-25°C | 大多数口服片剂 |
| 阴凉处保存 | 不超过20°C | 部分栓剂、软膏 |
| 冷藏保存 | 2-8°C | 胰岛素、部分眼药水、益生菌 |
| 遮光保存 | 避光 | 硝苯地平、维生素C |

### 2. 药品过期判断

- **严格有效期**：标注"有效期至XXXX年XX月"的药品，过期即不可使用
- **开封后有效期缩短**：
  - 眼药水：开封后4周
  - 糖浆剂：开封后1-3个月
  - 软膏剂：开封后6个月
  - 胰岛素：开封后28天（室温）

### 3. 变质药品识别

**出现以下情况应弃用：**
- 片剂变色、碎裂、有异味
- 胶囊粘连、变形、变软
- 液体制剂浑浊、有沉淀（需摇匀后仍不消失）
- 软膏油水分离
- 栓剂变形、变色

## 七、药物中毒急救

### 1. 误服药物的应急处理

**第一步：确认以下信息**
- 误服了什么药物？
- 大约误服了多少？
- 什么时候误服的？
- 患者年龄、体重？

**第二分：一般处理原则**
1. **拨打120急救电话**
2. **不要随意催吐**（某些腐蚀性物质催吐会造成二次伤害）
3. **保留药品包装和剩余药品**，供医生参考
4. **记录患者意识状态、呼吸、脉搏**

**第三步：等待救援时**
- 患者清醒且呼吸正常：保持舒适体位
- 患者昏迷但有呼吸：侧卧位（防止呕吐物窒息）
- 呼吸心跳停止：立即进行心肺复苏（CPR）

### 2. 常见药物中毒特征

| 药物 | 中毒症状 | 特殊处理 |
|------|---------|---------|
| 对乙酰氨基酚过量 | 恶心呕吐→肝区痛→黄疸（延迟出现） | N-乙酰半胱氨酸解毒 |
| 安眠药过量 | 嗜睡→昏迷、呼吸抑制 | 保持气道通畅 |
| 降糖药过量 | 出汗、心悸、意识模糊（低血糖） | 口服糖水或静注葡萄糖 |
| 抗凝药过量 | 不明原因出血、瘀斑 | 维生素K拮抗 |

## 九、网络购药安全

### 网上药店识别
- **合法网上药店**必须有《互联网药品交易服务资格证书》
- 可在国家药监局网站查询（https://www.nmpa.gov.cn）
- **警惕以下风险**：
  - 声称"根治""特效"的药品
  - 价格远低于市场价的药品
  - 不需要处方就能购买处方药
  - 来源不明的进口药品
  - 通过社交媒体/直播带货的药品

### 识别假药的要点
1. 查看药品包装是否有**国药准字**批准文号
2. 可通过国家药监局网站或"中国药品电子监管码"查询
3. 正规药品包装印刷清晰，有防伪标识
4. 价格异常低廉要警惕
