# 常见穴位保健指南

## 一、穴位基础知识

### 1.1 什么是穴位
穴位（腧穴）是人体脏腑经络之气输注于体表的特定部位，是针灸、推拿、按摩等中医外治法的施术点。

穴位分类：
- **经穴**（十四经穴）：分布在十二正经和任督二脉上的穴位，共361个
- **经外奇穴**：不在十四经上但有固定位置和名称的穴位
- **阿是穴**：无固定位置，以压痛点或病变局部取穴

### 1.2 取穴方法
1. **骨度分寸法**：以骨节为标志，按比例折算
2. **体表标志法**：利用五官、肌肉、骨骼等体表标志
3. **手指同身寸法**：以患者本人手指宽度为度量
   - 中指同身寸：中指弯曲时中节两端纹头之间为1寸
   - 拇指同身寸：拇指指关节宽度为1寸
   - 横指同身寸（一夫法）：食指至小指四指并拢宽度为3寸

## 二、十大保健要穴详解

### 2.1 足三里（ST36）
- **归经**：足阳明胃经
- **位置**：外膝眼下3寸，胫骨前嵴外一横指（中指）
- **取穴**：正坐屈膝，用同侧手掌按在膝盖上，五指朝下，中指尖所到之处即是
- **功效**：健脾和胃、扶正培元、通经活络、升降气机
- **主治**：胃痛、呕吐、腹胀、泄泻、便秘、虚劳诸证
- **保健方法**：每日用拇指按揉3-5分钟，力度适中，以酸胀为度
- **适合人群**：消化不良、体质虚弱、亚健康人群
- **古语**：*"肚腹三里留"*——胃肠疾病首选足三里

### 2.2 合谷（LI4）
- **归经**：手阳明大肠经
- **位置**：手背第1、2掌骨间，第2掌骨桡侧的中点处
- **取穴**：以一手的拇指指间关节横纹放在另一手拇食指之间的指蹼缘上，拇指尖下即是
- **功效**：疏风解表、镇静止痛、通经活络
- **主治**：头痛、牙痛、咽喉肿痛、感冒、面瘫
- **保健方法**：用对侧拇指按揉，每次3-5分钟
- **注意**：孕妇禁用此穴
- **古语**：*"面口合谷收"*——面部口腔疾病首选合谷

### 2.3 内关（PC6）
- **归经**：手厥阴心包经
- **位置**：腕横纹上2寸，掌长肌腱与桡侧腕屈肌腱之间
- **取穴**：腕横纹向上量三横指（约2寸），两筋之间
- **功效**：宁心安神、理气止痛、和胃止呕
- **主治**：心悸、胸闷、失眠、胃痛、恶心呕吐、晕车
- **保健方法**：用拇指按揉或掐按，每次2-3分钟
- **急救用途**：晕车、恶心想吐时按压内关有立竿见影之效
- **古语**：*"心胸内关谋"*——心胸部疾病首选内关

### 2.4 百会（GV20）
- **归经**：督脉
- **位置**：头顶正中线与两耳尖连线的交点处
- **功效**：升阳举陷、醒脑开窍、宁心安神
- **主治**：头痛、眩晕、失眠、健忘、脱肛、子宫脱垂
- **保健方法**：用手指指腹轻轻叩击或按揉，每次3-5分钟
- **特殊功效**：提升中气，改善下垂类疾病

### 2.5 三阴交（SP6）
- **归经**：足太阴脾经
- **位置**：内踝尖上3寸，胫骨内侧面后缘
- **取穴**：内踝尖向上量四横指，胫骨后缘凹陷处
- **功效**：健脾益血、调肝补肾、安神助眠
- **主治**：月经不调、痛经、带下、遗精、失眠、消化不良
- **保健方法**：拇指按揉，每次3-5分钟
- **注意**：孕妇禁用此穴
- **特殊意义**：此穴为肝、脾、肾三条阴经的交会穴，一穴调三经

### 2.6 涌泉（KI1）
- **归经**：足少阴肾经
- **位置**：足底前部凹陷处（足趾跖屈时）
- **取穴**：足底前1/3与后2/3交界处的凹陷中
- **功效**：滋阴降火、醒脑开窍、引热下行
- **主治**：头晕、失眠、咽喉肿痛、小便不利、足心热
- **保健方法**：睡前用热水泡脚后，用拇指按揉涌泉穴3-5分钟
- **特殊功效**：引火归元，治疗上热下寒证

### 2.7 中脘（CV12）
- **归经**：任脉
- **位置**：前正中线上，脐上4寸
- **取穴**：胸骨下端与肚脐连线的中点
- **功效**：健脾和胃、降逆利水
- **主治**：胃痛、腹胀、呕吐、泄泻、消化不良
- **保健方法**：用手掌顺时针按揉，每次5分钟
- **特殊意义**：胃之募穴，八会穴之腑会

### 2.8 太冲（LR3）
- **归经**：足厥阴肝经
- **位置**：足背第1、2跖骨结合部之前凹陷中
- **取穴**：足大趾和二趾之间的缝纹头向后推到两骨结合部前的凹陷处
- **功效**：疏肝理气、平肝息风、清热利湿
- **主治**：头痛、眩晕、目赤肿痛、胁肋疼痛、月经不调、失眠
- **保健方法**：用拇指从太冲向行间方向推揉，每次3-5分钟
- **特殊功效**：消气穴，生气时按揉可疏解郁闷

### 2.9 关元（CV4）
- **归经**：任脉
- **位置**：前正中线上，脐下3寸
- **取穴**：肚脐向下量四横指
- **功效**：培元固本、补益下焦
- **主治**：遗尿、遗精、月经不调、痛经、腹泻、虚劳
- **保健方法**：用手掌搓热后捂在关元穴上，或用艾灸温补
- **特殊意义**：小肠募穴，为先天之气海

### 2.10 风池（GB20）
- **归经**：足少阳胆经
- **位置**：胸锁乳突肌与斜方肌上端之间的凹陷中
- **取穴**：后颈部，枕骨之下，两条大筋外侧凹陷处
- **功效**：疏风清热、醒脑开窍、明目利窍
- **主治**：头痛、眩晕、颈项强痛、感冒、鼻塞、耳鸣
- **保健方法**：双手拇指同时按揉两侧风池穴，每次3-5分钟
- **特殊功效**：防治感冒的要穴

## 三、常见症状穴位处方

### 3.1 头痛
- **前额痛**：合谷 + 内庭 + 印堂
- **偏头痛**：太阳 + 率谷 + 外关 + 足临泣
- **后头痛**：后溪 + 风池 + 天柱
- **头顶痛**：百会 + 太冲 + 涌泉

### 3.2 失眠
- **主穴**：神门 + 三阴交 + 百会 + 安眠穴
- **配穴**：心脾两虚加心俞、脾俞；肝火旺盛加太冲、行间
- **按摩时间**：睡前30分钟

### 3.3 颈椎不适
- **主穴**：风池 + 天柱 + 大椎 + 后溪
- **配穴**：肩井 + 曲垣 + 天宗
- **自我保健**：每日做颈部旋转运动，配合穴位按揉

### 3.4 消化不良
- **主穴**：足三里 + 中脘 + 天枢
- **配穴**：内关 + 公孙 + 脾俞
- **方法**：餐后30分钟，顺时针按揉腹部配合穴位按压

### 3.5 腰痛
- **主穴**：委中 + 肾俞 + 腰阳关 + 阿是穴
- **配穴**：太溪 + 昆仑
- **古语**：*"腰背委中求"*

### 3.6 眼睛疲劳
- **主穴**：睛明 + 攒竹 + 太阳 + 四白
- **配穴**：合谷 + 光明
- **方法**：闭眼后轻柔按揉眼周穴位

### 3.7 感冒初起
- **主穴**：风池 + 合谷 + 大椎 + 迎香
- **方法**：用力按揉至微微出汗
- **配合**：喝热姜汤，盖被发汗

### 3.8 痛经
- **主穴**：三阴交 + 关元 + 气海 + 地机
- **配穴**：太冲 + 血海
- **方法**：经前一周开始按揉，每日2次

## 四、穴位保健手法

### 4.1 按法
用拇指或手掌垂直按压穴位，逐渐用力，持续数秒后放松，反复操作。
- 适用于：深层穴位，需要较强刺激

### 4.2 揉法
用指腹或掌根在穴位上做轻柔的环形旋转运动。
- 适用于：大多数穴位保健，力度温和

### 4.3 推法
用拇指或掌根沿经络方向做单方向直线推动。
- 适用于：疏通经络，如从太冲推向行间

### 4.4 摩法
用手掌在体表做环形摩动，不带动皮下组织。
- 适用于：腹部穴位（中脘、天枢、关元）

### 4.5 捏法
用拇指和食指（或中指）对合捏住穴位或肌肉。
- 适用于：耳穴、合谷、列缺等

### 4.6 叩法
用指尖或空拳有节律地叩击穴位。
- 适用于：百会、大椎等督脉穴位

### 4.7 艾灸法
用艾条在穴位上方2-3厘米处悬灸，每次10-15分钟。
- 适用于：虚寒体质，阳气不足
- 常灸穴位：足三里、关元、气海、神阙

## 五、穴位保健注意事项

### 5.1 禁忌
1. 孕妇禁用合谷、三阴交、至阴等穴
2. 皮肤破损、感染处不宜按摩
3. 饭后不宜立即按摩腹部穴位
4. 过度疲劳、饥饿时不宜强刺激
5. 严重心脏病患者慎用强刺激手法

### 5.2 注意事项
1. 按摩前清洁双手，修剪指甲
2. 力度以"酸胀但不疼痛"为宜
3. 每个穴位按摩3-5分钟为宜
4. 坚持每日按摩，效果更佳
5. 按摩后适当饮温水，促进代谢

### 5.3 何时就医
穴位保健是辅助养生手段，以下情况应及时就医：
- 持续性剧烈疼痛
- 不明原因的肿块
- 症状持续加重
- 伴有发热、出血等严重症状
